# ExchangeBoard — Android builds

Two APKs here:

- **`ExchangeBoard-v1.2.0-debug.apk`** — the phone app. Built from `android/app`
  via [Capacitor](https://capacitorjs.com/), wrapping the `dist/` web build
  from `main`, plus a hand-written native home-screen widget
  (`RateWidgetProvider`) that's not part of the Capacitor-generated project.
- **`ExchangeBoard-Wear-debug.apk`** — the Wear OS companion. Built from
  `android/wear`, a standalone hand-written native module (Kotlin) — a
  Tile + minimal companion activity, own `applicationId`
  (`com.cosmicgrub.exchangeboard.wear`), not wrapped/generated by Capacitor.

Neither is signed for release — sideloading/testing only.

## Install

```bash
adb install -r ExchangeBoard-v1.2.0-debug.apk        # phone
adb -s <watch-serial> install -r ExchangeBoard-Wear-debug.apk   # paired watch
```

The home-screen widget and the watch Tile both still need a manual
placement step on-device (long-press home screen / open the tile
carousel) — no app or install tool can add them on the user's behalf,
that's an Android/Wear OS platform restriction, not a limitation of these
builds.

## Rebuild from source

The `android/app` project is generated from the web app (`npx cap add
android` + `npx cap sync android`) — if the web app changes, regenerate
rather than hand-editing native files there. `android/wear` is hand-written
and independent of Capacitor/`npx cap sync`.

```bash
npm install
npm run build
npx cap sync android
cd android
JAVA_HOME="<path to a JDK 21>" ./gradlew assembleDebug
# phone -> android/app/build/outputs/apk/debug/app-debug.apk
# watch -> android/wear/build/outputs/apk/debug/wear-debug.apk
```

Built/tested against:
- App IDs: `com.cosmicgrub.exchangeboard` (phone), `com.cosmicgrub.exchangeboard.wear` (watch)
- JDK 21 (Android Gradle Plugin in this Capacitor version requires it — a
  JDK 17 `JAVA_HOME` fails with `invalid source release: 21`; Android
  Studio's bundled JBR works if you don't have a standalone JDK 21)
- Android SDK platforms 34–36, build-tools 34–36
- Wear module: `androidx.wear.tiles:tiles:1.2.0` (resolves against
  `androidx.wear.protolayout` for resources — see `RateTileService`'s
  imports if bumping this), minSdk 30 (Wear OS 3+)
